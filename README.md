# Visualizador de Perfil do GitHub

Uma aplicação web simples e intuitiva para buscar e visualizar perfis do GitHub utilizando a API oficial.

## 🚀 Funcionalidades

- **Busca de Usuários:** Pesquise qualquer usuário do GitHub pelo seu nome de usuário.
- **Informações do Perfil:** Visualize foto de perfil, nome, biografia e estatísticas de seguidores/seguindo.
- **Lista de Repositórios:** Acesso aos 10 repositórios públicos mais recentemente atualizados do usuário.
- **Estatísticas dos Repositórios:** Visualize estrelas, forks, watchers e a linguagem principal de cada repositório.
- **Design Responsivo:** Interface adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização customizada, animações e layout responsivo.
- **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM e consumo de API.
- **GitHub API:** Fonte dos dados de usuários e repositórios.
- **Devicons:** Ícones de desenvolvedor integrados.
